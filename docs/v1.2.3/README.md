# Zero-Mem v1.2.3 — Release Control System

**Status:** Planning control only. This documentation authorizes neither product implementation nor a GitHub release.

v1.2.3 exists to close the gaps found after v1.2.2: public composition, canonical sidecar discovery, Hermes full lifecycle, reproducible final evidence, and Windows/macOS qualification. It must not add unrelated retrieval, graph, vector, cloud, embedding, or automatic-injection features.

Start at [release-control-system/00-GUARDRAILS.md](release-control-system/00-GUARDRAILS.md). The ordered remediation plan is [release-control-system/01-FINDING-REMEDIATION-LEDGER.md](release-control-system/01-FINDING-REMEDIATION-LEDGER.md).

This is intentionally a small control system: one ledger, one implementation protocol, one E2E contract, one release gate and one work-package template. It applies to release-critical cross-boundary changes only.
