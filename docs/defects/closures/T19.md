# T19 evidence and proposed defects

Evidence: `tests/unit/test_t19_ui_*.py` (security, pages, ingest, CLI) and a headless Chromium run (login exchange, approve and kill-switch
form posts without JavaScript, HttpOnly/SameSite cookie, no horizontal overflow at 400 px light/dark).

| Proposed ID | Finding | Status |
|---|---|---|
| DEF-130 | Control panel `Referrer-Policy: no-referrer` makes Chromium send `Origin: null` on same-origin form posts, so the strict Origin check rejected every owner form. Found only in a real browser (http.client tests could not). Fixed: `same-origin`. | fixed in T19 |
| DEF-131 | Rendering `Markup + Markup` yields a plain `str` that is escaped again (settings path showed literal `<code>`). Fixed with `join`; test added. | fixed in T19 |
| DEF-132 | A rejected add echoed the rejected credential back into the form textarea. Fixed: the text field is cleared on `rejected_secret`. | fixed in T19 |
| DEF-133 | Dark-mode danger button had low contrast (white on light red). Fixed. | fixed in T19 |
| DEF-134 (observation) | Library has no dry-run ingest; the panel preview calls the private `Memory._preflight` read-only. A public `Memory.preview_ingest` would be cleaner. | deferred |
