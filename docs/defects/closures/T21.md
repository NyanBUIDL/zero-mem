# T21 - sharing across named memories, control-panel Sharing page, end-to-end tests (evidence and proposed defects)

Branch `wt/t21` (base f3f9a68). `DEFECT-REGISTRY.md` was NOT edited; rows below are proposals.

## Proposed rows
- **DEF-150** (medium, fixed): a tombstone for an imported rule/decision/gotcha was only counted as "skipped" (T20 deferred it), so a
  proposal the owner had forgotten stayed pending forever and an approved copy was never flagged. Now: pending proposal withdrawn; approved
  item never deleted silently, the pull reports it and the audit records `import outcome=revoke_proposed` (owner then uses `review revoke`).
  The import event now stores the `proposal_id`. Tests: `test_t21_learned_tombstones.py`, e2e.
- **DEF-151** (low, fixed): `share ... --memory NAME` was parsed but ignored (`_data_root` raised "named memories not available"). It now uses
  the T18 selection (`dest=memory_name`, `workspaces.memory_scope`), so identity/keys, peers, grants, audit and imports live in the selected memory.
- **DEF-152** (low, fixed): the loopback discovery test bound-and-released a UDP port then relied on UDP delivery; it now retries and SKIPS
  when the OS drops or refuses the datagrams.
- **DEF-153** (low, fixed): `create_invite` accepted a public IP literal (`--host 8.8.8.8`); every joiner refuses it, so the owner got an unusable
  code. Now refused at creation (`not_lan_address`, exit 3).
- **DEF-154** (info): an invite has no checksum; a typo inside a non-critical field (the label) still pairs, a typo in the token/pin is refused
  cleanly (tests pin this). Not changed: the single-use token already makes mistyped codes harmless.
- **DEF-155** (info, extends DEF-122): `settings.toml` is global, so `sharing.enabled`, `import_into_recall` and the kill switch apply to every
  named memory at once; identities, peers and grants are per memory.
- **DEF-156** (low, open): the panel's Join / Plan / Pull run in the request thread (bounded by the 10 s connect + 30 s call timeouts and a
  one-operation lock); a slow owner holds one of the panel's connection slots. A background job would need a runtime queue.
- **DEF-157** (info): the panel CSP gains `script-src 'nonce-...'` on exactly one response (the invite view, for the copy button); T19's "no script
  anywhere" invariant still holds for every other page (tests `ROUTES` now include `/sharing`).
