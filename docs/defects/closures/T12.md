# T12 closure - cross-platform portability (proposed DEF-082..086)

Evidence: Linux simulation (RED tests in `tests/unit/test_t12_portability.py`, then GREEN) and a full-suite run with
`PYTHONUTF8=0 LC_ALL=C PYTHONCOERCECLOCALE=0` (ASCII default text encoding, a stricter superset of Windows cp1252).
Final plain suite: 2 failed (known root-only m9_6), 6174 passed, 14 skipped.

| Proposed ID | Observed | Root cause | Fix |
|---|---|---|---|
| DEF-082 | Windows: ~190x `ProvisioningError stream_busy (AttributeError)` plus knock-ons (CLI exit 2, `KeyError source_id`, empty recall). | NOT fcntl (`src.storage.coordination.locked` already has a LockFileEx branch). `append_canonical_event` called `os.pread`, which does not exist on Windows; the broad `except Exception` turned the AttributeError into `stream_busy`. The fd was also opened without `O_BINARY`. | `lseek`+`read` and `O_BINARY` in `zero_mem/provisioning.py`; guard test bans bare POSIX-only `os.*` calls in product code. |
| DEF-083 | Windows: `UnicodeEncodeError/DecodeError 'charmap'`. | CLI/MCP stdio use the ANSI code page when redirected; benchmark/test helpers wrote/read text without `encoding` (and `\n` -> CRLF changed hashed bodies). | `use_utf8_stdio()` (src/storage/platform.py) called by `zero_mem.cli.main` and the MCP server (`lf_newlines`); benchmarks write `utf-8`/`newline="\n"`; tests read/write explicit UTF-8; subprocess helpers decode UTF-8. |
| DEF-084 | Windows: `test_walk_yields_sorted_relative_names...` lost `sub/deep/d.docx`. | `DirEntry.stat()` on Windows reports `st_dev == st_ino == 0`; every nested directory looked like its own ancestor (false `symlink_loop`). | `_dir_identity()` uses `os.stat` (inode) with a normalized-realpath fallback; real symlink loops are still detected (test). |
| DEF-085 | macOS: 19x `MemoryConfigError: unsafe data directory`. | Benchmark temp roots were created under `/var/folders` (`/var` -> `/private/var` alias) and the layout safety check rejects symlinked ancestors. | The benchmark hands `Memory` the resolved path. The security check is unchanged; tests pin that an unresolved symlinked ancestor and a symlink planted inside the data dir are still rejected. |
| DEF-086 | Windows: `os.mkfifo` AttributeError, `assert 511 == 448`. | POSIX-only primitives in tests. | `skipif(not hasattr(os, "mkfifo"))` on the two FIFO tests; POSIX mode asserts guarded by `os.name != "nt"` (behaviour unchanged on POSIX). Source-scan tests read UTF-8 (`test_m7_2 ... test_no_m8_features` read a src file with byte 0x81). |

Not reproducible on Linux: `assert 2 == 0` x4 (believed CLI knock-ons of DEF-082, unconfirmed); actual
LockFileEx behaviour, `os.replace` over open handles, MAX_PATH, case-insensitive FS.
Unchanged by design: stored `external_ref`/relative names stay `/`-normalized (walk builds them with `/`).
