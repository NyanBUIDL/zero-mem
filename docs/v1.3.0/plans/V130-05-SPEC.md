# V130-05 SPEC — Hybrid corpus benchmark N=5.000+

**Finding nguồn:** `docs/v1.3.0/analysis/P1-05-benchmark-scale.md`
**Depends:** V130-01..04 | **Gate:** G0→G5

## Contract

### Synthetic corpus (deterministic)
- Generator: `benchmarks/v130_synthetic_generator.py`, seed cố định (hằng số trong code, không random thời gian chạy). Timestamps derive từ seed. Chạy 2 lần → byte-identical (sha256 so sánh — D1).
- Sinh N≥5.000 memory events có cấu trúc điều khiển: ks phân bố K spaces, state/decision cạnh tranh timestamp, supersession chains, term hiếm/phổ biến.
- Case sets nhắm từng fix:
  - OR-fallback: multi-term queries term-hiếm (recall gain) + term-phổ biến (precision guard — AND không fallback).
  - ks filter: query ks-a phải 0 hit trên ks-b (leak=0).
  - state promotion: PROJECT query với active state + decisions cùng timestamp → state phải vào set.
  - temporal: as_of trước/sau supersession → stale visible.
- Metrics: precision/recall per case-set, ghi RAW (không tô hồng).

### Real corpus pipeline
- Export read-only từ `zero-mem-dev-data/_archive/` JSONL → REDACTION GATE (test riêng fail-closed với known-secret fixture) → fixtures CHỈ dưới `zero-mem-dev-data/benchmarks/v130/`.
- Xác nhận fixtures KHÔNG trong git track (`git status --porcelain` sạch) và không vào release artifacts.
- Metrics: token-savings (EvidenceSet estimated_tokens vs naive full-history tokens) + stale-visible rate.

### Before/after
Chạy benchmark trên pre-fix baseline (git stash/commit trước từng WP) và sau từng fix; log raw vào evidence dir per WP.

### Isolation
Chạy với TMPDIR/HOME tạm đúng checklist §A; không ghi vào Hermes home thật.

## Acceptance criteria
1. D1 determinism: 2 lần chạy generator → hash giống nhau (bằng chứng trong evidence).
2. Redaction gate test pass; known-secret bị chặn.
3. Fixtures ngoài git track (bằng chứng `git status`).
4. Per-fix metric có expected outcome tường minh; số liệu before/after raw trong EVIDENCE.md.
5. Runtime ghi thô (không tối ưu sớm).
6. stale_safe + isolation kiểm chứng.
