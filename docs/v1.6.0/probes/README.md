# v1.6.0 Probes

Probe lịch sử DEF-034 vẫn ở [`docs/v1.6/probes`](../../v1.6/probes/) để không
phá đường dẫn đã được dẫn chiếu. Probe DEF-037 nằm trong
[`audit/evidence-v160-def037`](../../../audit/evidence-v160-def037/).

Probe mới của v1.6.0 nên đặt trong thư mục này và phải ghi command, platform,
Python version, exact SHA và dữ liệu đã được sanitize.
