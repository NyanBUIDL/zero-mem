# WP-02 Task Packet — Core and Adapter Boundaries

## Authority

Derived from planning ref `2f1763f1335326b83bf90f263cada5c3715f21eb`, the WP-02 contract, ADR-001/ADR-002, and current source inspection. The WP document was recovered read-only from the planning ref because it is absent from the durable implementation tree; this packet records that self-reconciliation.

## Objective

Introduce a public, host-independent core/client boundary while preserving existing adapter behavior and compatibility. Runtime state must be client-owned and immutable; Hermes-specific translation remains in adapters.

## Production call graph

- Generic entry: `zero_mem.core.ZeroMemClient` → client-owned `ZeroMemRuntime`/configuration → injected writer or explicit unavailable result.
- Hermes entry: `Hermes plugin context.register_hook` → `src.integration.hermes_registration.RegistrationAdapter` → callback → existing mapping/capture adapter, with runtime state supplied by the client boundary.
- Hermes read entry: `Hermes plugin context.register_tool` → `HermesReadAdapter` → existing M6 dispatcher → authorized read service.
- Release composition: `zero_mem.hermes_integration.HermesBoundary` → adapter construction/registration.

## Forbidden scope

Canonical DOCX, Product Memory, remote Git, destructive Git operations, dependency metadata, storage algorithms, retrieval/ranking redesign, WP-08 signatures, WP-07 hook semantics, WP-21 transport, and all paths not listed above.

## Frozen gates

- core/client modules do not import Hermes-specific modules or host plugin APIs;
- two clients with distinct immutable configuration coexist without global cross-talk;
- adapters consume the boundary without taking ownership of authorization/storage/ranking;
- incomplete capture construction is unavailable unless writer and consistency policy are explicit;
- existing boundary and regression tests remain green;
- negative import/authority tests pass; benchmark records overhead without a release claim;
- canonical/Product Memory/Git boundaries remain intact.
